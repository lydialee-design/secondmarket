# 台中第二市場介紹網站

一個展現台中百年古蹟「第二市場」歷史風華與在地道地美食的響應式數位導覽網站。本專案採用懷舊復古風格設計，整合了 HTML5 語意化標籤、CSS Flexbox / Grid 佈局以及 RWD 響應式網頁設計。

---

## 專案介紹

* **專案主題**：台中第二市場導覽網站
* **設計風格**：懷舊復古風（配色以米白 `#f8f4ef`、磚紅 `#87392e`、黃棕 `#e4d7ca` 與深木褐 `#302823` 為主色調）
* **專案目的**：提供遊客與美食饕客完整的市場歷史簡介、三大特色、熱門攤位推薦、公視影音報導、地圖定位與交通指引。
* **主要功能**：
  * Sticky 頂部導覽列與頁首回升錨點。
  * 側邊欄參觀資訊與快速章節導覽。
  * 響應式雙欄/單欄排版與手機版選單支援。
  * 整合 Google 地圖嵌入與 YouTube 官方影音報導。

## 使用技術

* **HTML5**：使用語意化標籤（`<header>`, `<nav>`, `<aside>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`）提升 SEO 與無障礙體驗。
* **CSS3**：
  * **Flexbox & Grid**：用於頂部導覽列、二欄式版面主結構與區塊卡片排版。
  * **CSS Media Queries**：針對平板（< 1000px）與手機（< 600px）進行平滑單欄轉換與響應式字型調整。
* **JavaScript**：基礎 DOM 控制邏輯（手機版漢堡選單展開/收合）。
* **第三方嵌入 API**：
  * **Google Maps Embed API**：第二市場經緯度地圖嵌入。
  * **YouTube Iframe Player API**：公視《我在市場待了一整天》EP6 報導嵌入。
